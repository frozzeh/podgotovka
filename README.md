# podgotovka

calculus — тренажёр по алгебре, функциям и области определения перед Calculus I.

- Диагностика: 12 вопросов из банка на 24 задания.
- Практика с решениями по шагам.
- Отдельные аккаунты ученицы и наставника.
- Закрытая история ответов и редактируемый план обучения в Supabase.
- Режим подробных объяснений с более простыми заданиями.

Сайт: https://frozzeh.github.io/podgotovka/

## Использование

Наставник входит в кабинет, создаёт учебную группу и передаёт ученице код приглашения. Ученица входит отдельно и присоединяется по коду. В кабинете наставника доступны ответы и план; личные данные хранятся в Supabase, а не в GitHub.

В `config.js` используется публичный publishable ключ. Секретных ключей и ответов пользователей в этом репозитории нет. Доступ к данным ограничен политиками Postgres RLS.

Перед регистрацией реальных пользователей необходимо настроить почтовую отправку и production Site URL в Supabase. До этого задания доступны в деморежиме без общей синхронизации.
